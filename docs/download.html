After you download

Three stops to your first backup.

  1. Open the file

    Double-click it. If Windows says it protected your PC, choose More info, then Run anyway. The app is not code-signed yet.

  2. Connect your phone

    Plug it in and unlock it. The guide shows the three ways to connect.

  3. Press Back up now

    Your backup lands in a normal folder named after your phone.

Check your copy

Each release lists a SHA-256 checksum in SHA256SUMS.txt. In PowerShell, run this in the folder you downloaded to; the long number it prints should match.

Get-FileHash PhoneBackup-*.exe

Build it yourself

Install Rust, download the source code, then run this in its folder.

cargo build --release
