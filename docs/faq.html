Getting started

Is it really free?

Yes. No paid version, no trial, no ads. It is open source under the GPL-3.0 license, so anyone can read and check the code.

What do I need?

A 64-bit Windows PC, an Android phone and a USB cable that carries data, not only charge. Wi-Fi works after a one-time setup.

Windows says it protected my PC. Is the app safe?

Windows shows this for apps that are not code-signed. Signing costs money every year, so this free app is not signed yet. Choose More info, then Run anyway. To be sure your copy is the real one, compare its checksum with the one on the download page.

Do I need USB debugging?

Only for apps, contacts, calls, messages, the calendar and Wi-Fi. Photos, videos and files copy with plain File transfer.

My phone does not show up.

Unlock it, choose File transfer in its USB notification, and try another cable or USB port; many cables only charge. With USB debugging, tap Allow on the phone. The phone card in the app shows the steps for Samsung, Xiaomi, OnePlus, Vivo, Pixel and others.

Does it work with an iPhone or a Mac?

Not yet. It backs up Android phones on Windows.

Your backups

Does every backup copy everything again?

No. Each phone has its own folder, and later backups copy only new or changed files.

Can I go back to an older backup?

Yes. When a file or your messages change, the copy that was replaced moves into the backup's history folder instead of being lost. On Restore, press Version to restore or read the backup as it was after any earlier backup. Settings says how many older versions to keep; the latest copy of every file always stays.

Can I open a backup without the app?

Yes. It is a normal folder. Photos open as photos, contacts are in contacts.vcf for Google Contacts or any phone, and Export makes spreadsheets and pages you can print.

Are my app logins and WhatsApp chats included?

Apps are saved so they can be reinstalled, but without their logins and data, because Android does not let other apps read them. Photos and files in WhatsApp's folder come along with your other files.

What if something fails halfway?

What was copied stays copied. The app says which files failed in report.txt; back up again to try those files again.

Privacy

What does the app read?

The phone you connect, to show what is on it. It copies only what you choose, and only when you start a backup, restore or tool.

What is the helper on my phone?

To read contacts, calls, messages and the calendar, the app puts a small helper app on the phone and removes it when the backup ends. It sends data only to your computer, over the USB debugging connection. Its code is public too.

Does the app go online?

Only when you click Get adb, to download it from Google, or Check for updates, to ask GitHub for the newest version. It never sends your data. There is no account, no ads and no tracking.

Is my backup encrypted?

Only if you give it a password. Without one, backups are ordinary files, so anyone who can open the folder can read them. On Restore, Lock on a backup encrypts either its contacts, calls, messages and calendar, or everything copied from the phone. Each file is encrypted with AES-256-GCM under a key made from your password with Argon2id. Later backups into it are encrypted too.

What does the password not hide?

File and folder names, sizes and dates stay visible, and so do the backup's checksums and its list of versions. Exports and opened attachments are ordinary files. With only personal data protected, photos and files stay ordinary files that open in Explorer.

What if I forget the password?

Use the recovery key shown when you set the password: the password prompt offers it, and you then choose a new password. Without the password or the recovery key, nobody can open the backup, not even Phone Backup. The password is never saved anywhere.

Can I check a protected backup without the password?

Yes. Verify checks the encrypted files against their checksums, so it needs no password. Reading, exporting and restoring ask for it once; it stays unlocked until you close the app.

How do I remove everything?

Delete the backup folder to remove your backups; deleting the app keeps them. The app's settings are in your Windows user folder (AppData).

Does this website track me?

No cookies and no analytics. The download page asks GitHub for the newest version, so GitHub sees your internet address, as any website does.

I found a bug.

Open an issue on GitHub. Settings in the app can save a diagnostics file to attach; read it before you share it. Report security problems privately, as described in the security policy.
